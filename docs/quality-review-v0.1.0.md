# MVP v0.1.0 1차 품질 검수

검수일: 2026-09-09. Flutter 3.47.2 / Dart 3.13.2, Windows 환경.
기능 확장 없이 기존 MVP를 검수했습니다. commit/push는 실행하지 않았습니다.

## 1. 발견한 문제

- 잘못된 운동 시간이 미리보기에서 0분으로 해석되고, 허용 범위 밖 몸무게로도 미리보기가 계산됐습니다.
- 입력 완료 후 칼로리와 저장 버튼을 찾기 위해 스크롤해야 했습니다. 포커스 이동과 탭 전환 시 키보드 정리가 명시적이지 않았습니다.
- 알림 시간 변경도 권한 요청 경로를 사용했습니다. 앱 재진입마다 재예약하면 아직 도착하지 않은 당일의 지연 알림이 다음 날로 밀릴 수 있었습니다.
- 날짜 축 자동 라벨은 좁은 화면에서 겹칠 수 있었고, 몸무게 눈금을 정수로 반올림하면 서로 다른 눈금이 같은 값으로 보일 수 있었습니다.
- 미기록 날짜 사이에도 선이 연결됐습니다. 0분 기록과 미기록의 의미를 구분하는 설명이 없었습니다.
- 저장소 자체의 비정상 날짜·NaN·Infinity 검증이 부족했습니다. 비동기 날짜 조회가 겹쳤을 때 이전 응답을 걸러내지 않았습니다.
- 저장 버튼 고정 후 기존 Snackbar가 버튼을 가리는 회귀를 테스트에서 발견했습니다.
- 버전은 1.0.0으로 표시되어 요청한 0.1.0과 달랐습니다.

## 2. 수정한 내용

숫자 미리보기 검증, 저장소 입력 검증, 비동기 조회 세대 확인, 달력 기준 이전 날짜 계산을 적용했습니다. 날짜 UNIQUE 및 트랜잭션 UPDATE/INSERT 구조는 검토 결과 유지했습니다.

알림 권한 요청은 OFF → ON에서만 수행합니다. 시간 변경은 기존 ID 1을 갱신하고, 같은 시간대의 대기 예약은 앱 재진입 시 보존합니다. 시간대 변경 또는 예약 유실 시 재예약합니다.

그래프는 미기록 날짜에서 선을 끊으며, 실제 0분 기록은 점으로 남깁니다. 몸무게 축은 최소 2kg 범위를 확보하고 소수 눈금을 사용합니다. 운동 시간·칼로리 축은 0에서 시작하고 정수 간격을 사용합니다. 날짜 라벨은 첫/마지막 날짜만 표시하며 툴팁에도 연도를 포함합니다.

pubspec와 앱 정보를 0.1.0으로 맞추고 CI 포맷 검사 범위를 `.`으로 통일했습니다.

## 3. UX 개선 내용

- 칼로리와 저장 버튼을 하단에서 바로 확인합니다. 별도의 확인 팝업은 추가하지 않았습니다.
- 몸무게 → 시간 → 거리의 다음/완료 동작을 연결하고, 운동 프리셋 선택 후 시간 필드에 포커스를 둡니다.
- 스크롤 또는 탭 전환 시 키보드를 정리합니다. 검증 실패 시 해당 필드가 보이도록 스크롤합니다.
- 예상값은 `예상 소모 칼로리`, `약 … kcal`로 표시합니다. 잘못된 입력은 `— kcal`, 운동 0분은 `약 0 kcal`입니다.
- 짧은 저장 피드백은 대기열에 쌓지 않고 저장 버튼 위에 표시합니다. 저장 실패 시 입력은 유지합니다.
- 저장된 날짜에는 `저장된 기록`, `기록 수정하기`가 표시됩니다.
- 큰 글꼴에서도 필터가 줄바꿈되며, 설명·오류 문구가 한 줄로 잘리지 않도록 했습니다.

Light/Dark × 일반/큰 글꼴의 세 화면, 총 12개 로컬 렌더 이미지를 만들고 주요 화면을 육안 확인했습니다. 이는 Flutter 위젯 렌더링이며 Android 실제 IME·OS 글꼴·시스템 바 검증을 대체하지 않습니다. 실제 30초 완료 시간은 측정하지 않았습니다.

## 4. 데이터/알림 검증

- 실제 SQLite 엔진으로 신규 저장, 동시 저장, 날짜 중복 방지, id/createdAt 보존, updatedAt 갱신을 확인했습니다.
- 최근 몸무게 조회는 선택 날짜 이전 값만 사용하며 null 측정일을 건너뜁니다. 계산에 대체한 몸무게는 새 측정값으로 저장하지 않습니다.
- 거리 null, 명시적 0분 기록, 미기록 날짜, 7일/30일/전체 경계 및 순서를 검증했습니다.
- 알림 기본 OFF, 권한 거부, ON 시 한 번만 요청, 시간 변경 시 단일 ID, OFF 취소, 외부 권한 철회, 예약 실패, 시간대 변경을 Android 플랫폼 채널 모의 테스트로 검증했습니다.
- AndroidManifest의 POST_NOTIFICATIONS, RECEIVE_BOOT_COMPLETED, 예약/부팅 수신기와 Gradle desugaring, 알림 아이콘 보존 설정을 확인했습니다. 패키지의 Android 13+ 권한 분기도 코드로 확인했습니다.
- MET 공식은 독립 유틸리티에, 프리셋 값은 enum 한 곳에 있습니다. 기존 값은 대표 강도 근삿값으로 유지했습니다. 최신 Compendium과의 비교 및 출처는 README에 있습니다.

## 6. 실기기에서 확인할 내용

Android SDK와 연결된 Android 기기가 없습니다. 요청에 따라 SDK를 설치하지 않았고 APK 빌드를 수행하지 않았습니다. iOS 빌드도 미검증입니다.

- 설치 및 콜드 스타트 속도, 실제 30초 입력, Android 숫자 키보드와 접근성 서비스.
- 앱 프로세스 종료/재실행 후 저장 데이터 유지.
- Android 12 이하/13 이상에서 실제 알림 권한·수신·취소, 절전 및 재부팅 복원.
- 앱 종료 상태에서 시간대 변경 시 다음 앱 진입 전에는 기존 예약 시간대가 적용될 수 있습니다. 재진입 후 현지 시간 재예약은 자동 테스트로 검증했지만 종료 상태의 즉시 시간대 전환은 보장하지 않습니다.
- iOS 권한·알림, Android 릴리스 서명 및 실제 APK 빌드. 현재 릴리스 서명은 Flutter 기본 개발용 설정입니다.

## 7. Git 상태와 커밋 판단

기준 HEAD에는 README만 있어 Flutter 프로젝트 파일은 대부분 아직 미추적 상태입니다. 이번 검수에서도 stage/commit/push는 하지 않았습니다. `.tools` SDK, 캐시, 렌더 이미지는 Git 제외 대상입니다.

**소스 및 자동 검증 기준으로 MVP v0.1.0 커밋에 적절합니다.** Android 빌드와 실기기 검증을 완료한 배포 승인 상태라는 의미는 아닙니다.
