# Character / Profile Growth

Today의 compact Lv/Title은 프로필로 연결하고 오늘 걸음·운동 시작 순서는 유지합니다. 걸음과 퀘스트 진입은 기존 성장 화면을 사용합니다. 프로필에는 로컬 벡터 아바타, Lv/XP/타이틀, 누적 걸음·운동 거리·탐험 개수·업적 수만 표시합니다.

## 외형과 보상

`cosmeticId`는 `accent.purple.v1`처럼 안정적인 ID이며 `unlockRuleVersion = 1`입니다. 기본 세이지/안개/무프레임/심플, Lv 5 라일락, Lv 10 성장 프레임, 누적 운동 50km 발자취 프레임, 10지역 탐험가 엠블럼, 첫 운동 업적 새벽 배경, 운동 30회 꾸준함 엠블럼을 제공합니다. 외형에 별도 XP를 지급하지 않고 기존 GPS·걸음·탐험·XP 규칙을 유지합니다.

해금은 영구 이력이며 원본 운동 삭제 후에도 유지합니다. 장착은 저장된 해금·slot·catalog를 검사하고 잠긴 항목은 누를 수 없습니다. 타이틀은 기존 원장을 사용하며 하나만 장착합니다.

레벨·업적·탐험 업적·외형 보상은 UNIQUE key로 한 번만 저장합니다. 과거 사용자의 처음 진입은 현재 레벨 하나를 요약하며 자동 팝업은 없습니다. 보상함은 10개씩 표시하고 사용자가 확인한 페이지의 항목만 읽음 처리합니다. 미확인 항목은 사라지지 않으며 재시작/백업 후에도 확인 상태를 보존합니다.

## 데이터와 성능

schema 5는 `character_progress` 테이블 하나를 추가합니다. 기존 테이블·raw GPS는 바꾸지 않습니다. 기존 schema 1~4 upgrade 경로를 유지합니다. backup format 3 / schema 5는 기존 8개 테이블에 프로필 테이블 하나를 추가합니다. format 1·2도 읽으며 손상되거나 알려지지 않은 외형·보상 레코드는 교체 전에 거부합니다. 이전 백업에는 프로필 저장 상태가 없어 장착·보상 확인을 초기화하고 복원된 활동으로 다시 해금합니다. format 1의 기존 걸음/성장 유지 정책은 그대로입니다.

프로필은 진입·사용자 조작·foreground 복귀에만 갱신합니다. 추가 timer/sensor/GPS subscription·dependency·백그라운드 작업이 없습니다. 공유는 같은 벡터 아바타를 720×720 이미지로 그리며 Lv·타이틀·걸음·운동 거리·탐험 개수만 허용합니다. 위치·경로·시각·체중·내부 ID는 넣지 않습니다. 기존 preview→시스템 공유/갤러리 저장 경로를 재사용합니다.

## 검증

프로필 전용 테스트 15개는 XP 불변, 동시 해금 중복, 레벨 경계, 잠긴 외형 차단, 원본 삭제 후 해금 유지, 보상 확인 중복, schema 1/4→5 보존, 모든 백업 테이블 왕복, format 1/2 호환, 손상 외형 백업 거부, 잠긴 장착 fallback, Light/Dark 320dp·font 2와 PNG 크기·공유 필드 허용 목록을 확인합니다.

`dart format .`, `flutter analyze` 및 전체 Flutter 테스트 235개(비공개 S26 입력 4개 포함), native `:app:stepPolicyChecks` 9개가 통과했습니다. 비공개 입력이 없는 CI는 231개 실행/4개 skip이 예상됩니다. 로컬의 대용량 비공개 백업 테스트는 에뮬레이터 부팅과 동시 실행 시 기본 30초를 넘겨 `--timeout 2m`으로 전체 재검증했습니다. 앱 코드의 시간 제한이나 저장 동작은 변경하지 않았습니다.

S26 미연결 시 Diligent_API36을 사용합니다. 실제 센서 정확도·장시간 background/화면 OFF·배터리·야외 GPS·TalkBack 음성 탐색은 S26에서 검증해야 하며 에뮬레이터로 대체하지 않습니다.

2026-10-08에는 S26이 없어 Diligent_API36(Android 16/API 36)에서 정식 서명 APK 업데이트를 검증했습니다. schema 4→5 이후 기존 운동 3개, 경로/raw GPS 각각 2,703개, 일상 기록 1개, 걸음 일별 기록 7개, XP 원장 88개, 탐험 63개와 기존 타이틀·sensor cursor의 모든 열이 유지됐습니다. 라일락/새벽/탐험가와 타이틀 장착·재시작, 보상 9개 확인 후 미확인 0·XP 2,035 불변을 확인했습니다. 앱에서 format 3 백업을 내보내고 다시 복원한 뒤 9개 테이블의 모든 행/열이 내보낸 파일과 일치했습니다.

Light/Dark 프로필과 카드, 320dp·OS font scale 2.0을 확인하고 실제 MediaStore에 저장된 720×720 PNG 두 장을 시각 검토했습니다. 시스템 공유창은 열기까지만 확인했고 외부 전송은 하지 않았습니다. 부팅 중 OS 입력 ANR이 있어 에뮬레이터 stylus handwriting을 비활성화한 뒤 검증했으며 앱의 입력·서비스 코드는 바꾸지 않았습니다. 화면·백업·DB·로그 산출물은 `.tools/character-profile-20261008/`에만 두고 Git에 포함하지 않습니다.

자체 리뷰에서 반복 refresh의 기존 해금 INSERT 시도를 제거하고, 잘못된 외형 ID/slot·보상 레코드를 복원 전에 거부하도록 보강했습니다. 잠긴 장착 fallback과 원본 삭제 후 영구 해금 유지, 기존 XP 정책·개인정보 없는 공유 필드를 확인했습니다. 새 timer/센서/dependency/서비스 변경이 없으며 실제 배터리 절감이나 S26 센서 정확도를 이 검증으로 주장하지 않습니다.
