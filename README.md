# Diligent Life · 1.0.0-rc1 (11)

운동·몸무게의 변화를 기기에 보관하는 개인 라이프 트래커입니다. 광고, 계정, 앱 서버가 없습니다. 이번 RC는 v0.9.0 기능을 유지하고 데이터 보존·복구·배포 준비를 검증합니다.

## 주요 기능

- 오늘의 몸무게·수동 운동 기록과 기록 알림
- GPS 운동 시작, 일시정지, 재개, 종료 및 중단된 운동 복구
- 경로·속도·페이스, 500m/1km split, 전후반 비교, 정지 통계, GPS 품질 상세
- 신뢰도를 반영한 100m/500m/1km 최고 구간과 지도 선택
- 기간별 포트폴리오, 월간·연간 리포트, All-time Map, 이미지 공유
- 시스템 Light/Dark, 큰 글꼴, 접근성 이름, 로컬 파일 백업·복원

## 데이터와 계산 정책

SQLite schema 3을 사용하며 1→2, 1→3, 2→3 업그레이드를 지원합니다. 분석 재계산은 파생 캐시만 갱신하며 기존 운동 합계와 raw GPS를 수정하지 않습니다. raw GPS가 없는 과거 운동은 저장 경로로 제한적으로 분석합니다.

기록 당시 거리와 후처리 분석 거리는 서로 다른 기준이며 화면에서 구분합니다. 운동시간은 수동 일시정지를 제외한 기록 시간입니다. 이동·정지·미분류 시간은 GPS 분석 결과로, 신호가 부족한 시간을 이동으로 가정하지 않습니다. 칼로리는 기록 시간과 당시 체중의 MET 추정치이며 실제 소비량 측정이 아닙니다. 개인 기록에는 신뢰도와 최소 개선 임계값을 적용합니다. 상세 정책은 [v0.9 분석 정책](docs/analysis-v0.9.0.md)을 참고하세요.

원본에는 정확한 위치·시각·체중이 포함됩니다. 일반 기록은 앱의 로컬 저장소에 있으며 분석용 서버로 전송하지 않습니다. 지도는 OpenStreetMap 타일을 인터넷으로 요청하므로 타일 서버에 IP와 요청 영역이 전달됩니다. 이미지 공유는 미리보기 후 사용자가 시스템 공유창에서 선택합니다. 운동 공유의 시작·끝 위치 200m 숨김은 기본 켜짐이며 완전한 익명화를 보장하지 않습니다.

Android OS 자동 백업·기기 이전은 비활성화되어 있습니다. 앱 삭제·기기 분실 시 수동 백업이 없으면 복구할 수 없습니다. 앱 재시작은 마지막 커밋된 체크포인트의 진행 중 운동을 일시정지로 복원합니다. 비정상 종료 직전 미저장 데이터는 복구하지 못하며 종료된 동안의 시간·거리를 만들어 넣지 않습니다.

## 백업과 복원

1. 설정 → **기록 백업과 복원** → 내보내기에서 `.diligent` 파일을 안전한 개인 폴더에 저장합니다.
2. 복원 전에 현재 기록도 별도 파일로 내보냅니다.
3. 가져오기에서 파일을 선택하고 검증된 기록 수를 확인한 다음 전체 교체를 승인합니다. 병합하지 않습니다.

백업 format 1 / schema 3은 일일 기록, 운동 세션, 저장 경로, raw GPS의 모든 열을 보존합니다. 파생 캐시·지도 타일·알림 설정은 제외합니다. 기존 format 1 백업과 호환됩니다. 임시 DB에서 형식·관계·범위·완료 행·행 수를 검증하며 손상·미지원 파일은 원본을 바꾸지 않고 거부합니다. 교체 실패는 트랜잭션으로 롤백합니다. 진행 중 운동·미저장 입력이 있으면 복원을 차단하고, 백업의 미완료 운동은 일시정지로 복구합니다. 백업은 암호화되지 않으며 위치 숨김도 적용되지 않습니다.

## 개발·검증

Flutter 3.47.2 / Dart 3.13.2, JDK 17, Android SDK가 필요합니다. applicationId는 `com.v4n1lla.diligent_life`이며 앱 이름은 Diligent Life입니다. 버전 원본은 `pubspec.yaml`, 화면 표시는 `lib/app_info.dart`이며 테스트로 일치를 확인합니다.

```sh
flutter pub get
dart format .
flutter analyze
flutter test
flutter build apk --release
flutter build appbundle --release
```

GitHub Actions는 format 검사, analyze, test, release APK/AAB 컴파일을 수행합니다. 개인 세션은 저장소·CI에 포함하지 않습니다. 필요하면 `S26_REGRESSION_DATA`에 기존 로컬 JSON export 경로를 지정하여 원본을 읽기만 하는 회귀 테스트를 실행합니다. synthetic 12,005/24,001 표본과 다중 세션 성능 테스트는 CI에도 유지합니다.

## 서명과 알려진 제한

- `android/key.properties`가 없으면 release 모드 빌드도 개발용 키로 서명됩니다. **로컬/CI 검증용이며 정식 배포용이 아닙니다.** 정식 키·복구 정책과 배포 채널 확정은 1.0 출시 blocker입니다.
- 정식 서명은 Git에서 제외한 `android/key.properties`에 `storeFile`(절대 경로 권장), `storePassword`, `keyAlias`, `keyPassword`를 설정합니다. 키·비밀번호·APK/AAB는 저장소에 커밋하지 않습니다. 다른 서명의 기존 설치에는 덮어쓸 수 없으므로 삭제 전 반드시 백업해야 합니다.
- GPS 정확도, 제조사 절전, 실내·화면 OFF 환경에 따라 누락·오차가 생깁니다. GPS가 없는 구간은 보간해 기록을 만들지 않습니다. 지도는 인터넷이 필요하며 실패 시 다시 시도할 수 있습니다.
- 개발 실기기는 SM-G988N(Galaxy S20 Ultra)만 사용합니다. S26은 실사용 기기이며 별도 지시 없이 설치·조작하지 않습니다.
- 자동 semantics·터치 영역 검사와 실제 TalkBack 음성 탐색은 구분합니다. 장시간 야외·백그라운드 운동과 실제 보조기술 사용자 검증은 별도 확인이 필요합니다.
- iOS는 macOS/Xcode 빌드, 실기기 권한·백업 정책 검증 전 출시 대상에서 제외합니다.
